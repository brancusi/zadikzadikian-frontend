# Proposal UI kit

A click-through recreation of the system's core deliverable: an acquisition/project proposal aimed at institutions, curators, and collectors. Six spreads: Cover → Statement → Works → Future work → CV → Press. Navigate via the running head or arrow keys.

Composition only — every primitive comes from `components/`. Work titles, dimensions, and prices are **placeholders pending studio records** (catalog numbers A-001…A-028 are real, from the supplied photography). Bio, exhibition history, and press citations are factual (see readme.md sources).
